Download PosterPal.apk

On the phone

  1. Same Wi‑Fi as the PC. Keep PosterPal open on Windows (tray is enough).
  2. Open this page in Chrome:
  3. Tap Download. Android will warn that the file is from this site — that’s expected for a sideload.
  4. Allow install from Chrome / Files if asked. Open the APK.
  5. Paste the desk URL (same host as this page, without /get-app.html).

If download fails, Windows Firewall is blocking port 8080. Run PosterPal.bat as Administrator once, or allow Node/PosterPal through Private networks.
